# Story 8.2 - Orders service
**Acceptance criteria**
1. Placing an order reserves stock in catalog and prices lines from the reservation; oversell -> 409, unknown product -> 404,
   catalog down -> 502 (service stays ready).
2. Local failure after reserving triggers compensation (release). Cancel releases stock; invalid transitions -> 409.
3. Every state change writes an outbox event in the same transaction; relay endpoints are service-key protected.
4. Customers only see their own orders; admins see all.
