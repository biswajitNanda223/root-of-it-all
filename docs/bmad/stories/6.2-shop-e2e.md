# Story 6.2 - Shop end-to-end flow
**Acceptance criteria**
1. Create/list(filter,sort,paginate)/replace/patch/delete products; duplicate sku -> 409; bad sku -> 422.
2. Orders reserve stock all-or-nothing; `Idempotency-Key` replays without double reservation.
3. pending -> paid | cancelled only; invalid transitions -> 409; cancel restocks.
4. Timeline SSE and CSV export; `callbacks` + `webhooks` visible in OpenAPI.
