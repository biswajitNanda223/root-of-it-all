# Story 1.1 – uv workspace
**As a** developer **I want** one lockfile and shared packages **so that** apps stay consistent.
**Acceptance criteria**
1. `uv sync` installs `api`, `rio-core`, `rio-db` from the workspace.
2. `apps/*` may import `packages/*`, never the reverse.
3. Adding `apps/<new>/pyproject.toml` needs no root edit beyond `[tool.uv.sources]` if depended on.
