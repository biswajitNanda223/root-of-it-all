# Story 7.4 - Encrypted environment files (dotenvx)
**Acceptance criteria**
1. `scripts/env.sh init <env>` produces a committed file whose every value is `encrypted:`; the private key is only in `.env.keys`.
2. `dev.sh`, `start.sh`, `migrate.sh`, `docker.sh` run with the correct environment decrypted; exported variables override files.
3. Committing `.env.keys`, `.env.local`, plaintext secret values or an unknown `.env.*` is rejected by the hook and CI.
4. The runtime image contains no env files, keys or dotenvx.
**Status** Done
